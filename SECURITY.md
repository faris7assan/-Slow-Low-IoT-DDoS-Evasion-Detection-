# Security Policy

This repository contains controlled attack-emulation and detection research. Run the attack-generation components only in isolated environments and against systems you own or are explicitly authorized to test.

## Reporting

Do not publish credentials, private information, or sensitive exploit details in public issues. Contact the project owner through the GitHub profile with reproduction steps, impact, and remediation guidance.

## Secret Handling

Never commit API keys, passwords, tokens, private keys, `.env` files, or production credentials.
